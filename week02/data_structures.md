1. 상품코드를 입력하면 즉시 재고 수량을 확인해야 하는 재고 관리 데이터
    1. 선택한 자료구조: 딕셔너리
    2. 선택 근거: 상품 코드를 key로 하고 그에 대한 재고 수량을 value로 딕셔너리를 만들면 상품 코드를 입력하는 즉시 재고 수량을 확인할 수 있기 때문에 적절하다. 재고는 수시로 수정될 수 있으므로 튜플은 적절하지 않고, 리스트나 다른 자료구조는 상품 코드로 재고 수량을 즉시 찾을 수 없으므로 적절하지 않다.
    3. 예시 코드:
        ```
        stock = {"A101": 25, "B202": 3, "C303": 0}
        stock["A101"] -= 1 # 판매 시 즉시 차감
        code = input("상품코드: ")
        print(stock.get(code, "등록되지 않은 상품"))
        ```


2. 이벤트 응모 고객 명단에서 중복 응모를 제거하고, 기존 회원 명단과의 교집합을 구해야 하는 상황
    1. 선택한 자료구조: 집합
    2. 선택 근거: 집합을 사용하면 자동적으로 중복이 제거되고 기존 명단과 교집합을 구하기 용이하기 때문에 적절하다. 그외의 자료구조들은 중복을 제거하는 과정과 교집합을 구하기 까다로우므로 적절하지 않다.
    3. 예시 코드:
        ```
        applicants = ["u01", "u02", "u01", "u03", "u02"]
        members = {"u01", "u03", "u09"}
        unique = set(applicants) # 중복 자동 제거 → 3명
        winners = unique & members # 기존 회원과의 교집합
        print(len(unique), winners)
        ```

3. 월별 매출액을 1월부터 12월까지 순서대로 저장하고 순회하는 데이터
    1. 선택한 자료구조: 리스트
    2. 선택 근거: 순서가 존재하고 유동적으로 데이터를 수정할 수 있는 리스트가 적절하다. 튜플은 수정이 불가능하고 집합은 순서가 없기 때문에 적절하지 않다.
    3. 예시 코드:
        ```
        sales = [1200, 980, 1500, 1100, 1700, 2100, 0, 0, 0, 0, 0, 0]
        sales[6] = 1900 # 7월 매출 갱신
        for month, amount in enumerate(sales, start=1):
        print(f"{month}월: {amount:,}만원")
        print("상반기 합계:", sum(sales[:6]))
        ```

4. 한 번 발급되면 절대 변경되어서는 안 되는 (위도, 경도) 매장 좌표
    1. 선택한 자료구조: 튜플
    2. 선택 근거: 튜플은 한번 만들어지면 수정이 불가능하기 때문에 적절하다. 그외의 자료구조들은 실행 중 변경이 가능하기 때문에 적절하지 않다.
    3. 예시 코드:
        ```
        SHOP_COORD = (37.5665, 126.9780) # (위도, 경도) — 변경 불가
        # SHOP_COORD[0] = 0.0 # 수정 시 TypeError 발생
        shop_names = {SHOP_COORD: "서울 본점"} # 불변이라 key로 사용 가능
        ```

5. 1,000만 줄짜리 웹 서버 접속 로그 파일에서 특정 조건의 줄 수를 세는 작업 (자료구조 + 처리 방식 관점에서 서술)
    1. 선택한 자료구조: 제너레이터
    2. 선택 근거: 1,000만 줄 정도되는 크기의 데이터를 모두 메모리에 올려서 작업을 하는 것은 오류가 발생하기 쉽고, 요구사항이 특정 조건의 줄 수만을 요구하기 때문에 모든 내용을 기억하고 있을 필요가 없다. 제너레이터를 통해 필요한 줄만 하나씩 가져와서 특정 조건을 만족하는 줄만 세고 처리가 끝난 줄은 버린다.
    3. 예시 코드:
        ```
        def error_lines(path):
        with open(path, encoding="utf-8") as f:
            for line in f: # 한 줄 읽고 처리 후 버림
                if "ERROR" in line:
                    yield line
        print("에러 건수:", sum(1 for _ in error_lines("access.log")))
        ```
