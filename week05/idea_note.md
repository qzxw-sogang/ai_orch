1. 누가, 어떤 상황에서, 무엇 때문에 불편한가? 겪어 봤거나 관찰한 구체적 장면으로 서술  
    삼성전자의 적정 주당가치를 DCF로 계산해보려고 DART에서 사업보고서를 열었지만 현금흐름표 어디에도 잉여현금흐름이라는 항목이 없어 어떤 숫자를 활용해야 하는지 몰라 어려움을 겪었다. 잉여현금흐름을 겨우 계산한 뒤에도 향후 성장률을 몇 %로 넣어야 할지 근거를 찾지 못해 결국 감으로 숫자를 넣었다.  

2. 이 MVP를 실제로 쓸 사람은 누구인가? (예: 자취생, 동아리 총무, 소상공인)  
    주식 투자에 관심이 있고 기초적인 지식(가치평가 등의 개념을 알고 있는 상태)을 가지고 있는 초-중급자들  

3. 핵심 기능 (1~3개) MVP에 반드시 들어가야 할 최소 기능. 3개를 넘기지 않는다
    1. 사용자가 종목을 선택하면 재무 데이터를 보여준다.
        - 1번 추가 설명  
            데이터는 코스피200 기업(금융 관련 기업 제외)을 대상으로 DART(기업 재무제표), 공공데이터포털(주가), 한국은행(국채 금리) API를 통해 수집한다.  
    2. DCF 방식으로 적정 주당가치를 최악, 기본, 최선의 경우를 구분해 산출한다.(리버스 DCF도 같이 구현한다. 사용자가 직접 수치를 조정해볼 수 있도록 한다.)  
        - 2번 추가 설명  
        금융 관련 기업은 DCF가 아닌 RIM을 통해 분석하는게 더 용이하므로(잉여현금흐름 정의가 어려움) 제외했고 추후 확장 기능으로 검토한다.  
        리버스 DCF는 DCF의 역과정이므로 구현에 큰 자원이 소모되지 않는다고 판단했기에 하나로 포함했다.  
    3. 사용자가 뉴스나 증권사 리포트 등의 정보를 제공하면 그 내용을 분석해 가치평가에 반영한다.(사용자가 직접 수치를 조정해볼 수 있도록 한다.)  

4. LLM 활용 지점 어느 단계에서 LLM이 필요한가? (요약, 분류, 생성, 대화 등) LLM 없이도 되는 기능과 구분해 볼 것  
    - 기능 1  
        LLM이 없어도 되는 기능: API를 통해 데이터 수집한다.  
          
        기업마다 재무제표의 계정 과목을 다르게 하는 경우가 있으므로 표준계정 ID로 먼저 매칭하고, 매칭되지 않은 계정명을 분류하는 데 LLM을 활용한다.  
    - 기능 2  
        LLM이 없어도 되는 기능: 모든 대상 기업들의 기본 시나리오는 과거 재무 데이터를 활용해 코드로 DCF(리버스DCF)를 계산한다.  
          
        최악, 최선 시나리오는 기본 시나리오를 기준으로 LLM이 사업보고서의 사업 내용과 위험요인을 근거로 기본값 대비 조정폭을 제시한다. 이 과정은 분기마다 새로운 공시가 나올 때마다 실행해 DB에 저장한다.(시작할 때는 모든 사용자가 같은 데이터를 보게 된다.)  
        
    - 기능 3  
        사용자가 제공한 정보를 LLM이 분석해서 DCF의 파라미터에 어떤 영향을 미칠지 수치화해준다.(변화 근거, 변화량 등을 항상 같이 표시하고 같은 정보에 대해서는 같은 값이 나오도록 한다.)  
        LLM이 없어도 되는 기능: LLM이 산출한 수치를 기반으로 코드를 통해 재계산한다.

5. 어떤 데이터가 필요하며 PII 위험은 없는가? 더미 데이터로 대체 가능한가?  
    MVP 단계에서는 사용자의 개인정보(포트폴리오 데이터 등)를 활용할 계획은 없다. 공공에서 제공하는 실제 데이터(기업 재무제표, 주가, 금리)를 활용한다. 더미 데이터는 필요하지 않다.  
    기능3에서 사용자의 입력을 받아 LLM에 전달하기 때문에 프롬프트 인젝션의 위험성이 존재한다. 또한 사용자가 제공한 데이터는 저장하지 않는다.   

6. 기술적으로 가장 어려워 보이는 지점 1가지  
    - 기술적 지점  
        LLM의 환각으로 인해 수치가 평가할 때마다 달라진다면 신뢰성에 의심이 생길 수 있다. 일관성을 유지할 수 있는 방안을 고려한다.  
        예를 들면 LLM은 정해진 형식으로 변화량만 출력하고, 변화량에 상한을 두며, 같은 입력(같은 기사나 정보)은 저장된 결과를 재사용한다.

    - 그외 추가적인 고려사항  
        MVP 단계에서는 큰 고려 사항이 아니지만 이후 개인정보보호, 데이터 이용 그리고 유사투자자문업 규제 등과 관련해 법적으로 문제가 생기지 않도록 한다.
